flask webrtc android sharescreen control
================

基于webrtc实现的安卓远程控制系统



安装运行服务端 WebrtcPy
-------------
请按照以下顺序运行:
#### Requirements:
* python 3.x
* Flask
* Flask-SocketIO

安装python本地依赖:
```
pip install -r requirements.txt
```

运行:
```
python server.py
```

浏览器打开
```
http://localhost:5000/
```

运行客户端【被控端】AndroidControled
-------------
Android Studio Jellyfish | 2023.3.1
JAVA项目

打包控制端 VueControl
-------------
vue2
npm run build 
将打包后的dist文件夹中的index.html放到WebrtcPy/templates下，其余文件放到static下
