flask webrtc android sharescreen control
================

Android remote control system implemented based on WebRTC



Install and Run the Server: WebrtcPy
-------------
Run the following steps in order:
#### Requirements:
* python 3.x
* Flask
* Flask-SocketIO

Install local Python dependencies:
```
pip install -r requirements.txt
```

Run:
```
python server.py
```

Open in a browser:
```
http://localhost:5000/
```

Run the Client [Controlled Side]: AndroidControled
-------------
Android Studio Jellyfish | 2023.3.1
Java project

Build the Controller: VueControl
-------------
vue2
```
npm run build
```

Place the built `index.html` from the `dist` folder into `WebrtcPy/templates`, and place the remaining files into `static`.
